APEX

A vehicle-level engineering optimization platform that searches architectures across performance, range, packaging, cost, mass, thermal behavior, and robustness requirements.

OriginIndependent Project
ContextIndependent
PeriodPortfolio project
MaturityImplemented

Decision problem

Vehicle architecture decisions must trade performance, range, packaging, mass, cost, thermal behavior, and regulatory requirements before a fixed design is selected.

APEX optimizes the vehicle architecture itself rather than only the manufacturing process. It reuses a first-principles evaluation kernel across Pareto search, uncertainty propagation, surrogate modeling, and active learning.

DecisionWhich vehicle architectures remain feasible and attractive when requirements conflict and operating conditions vary?

System logic

How the work is structured.

01

Evaluate

Run longitudinal dynamics, battery, motor, mass, cost, and requirement calculations from a common physics kernel.

02

Search

Explore mixed continuous/discrete architecture choices with a real NSGA-II Pareto search.

03

Stress

Propagate payload, temperature, grade, wear, and battery-health uncertainty into chance-constrained feasibility.

04

Accelerate

Train Gaussian-process and random-forest surrogates, then use active learning to select the next informative designs.
